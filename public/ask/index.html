    Retrieval test

    Each test question has a known source document. The test checks whether that document is among the top 3 passages, with no model involved.

    –hit rate at 3 on the sample library

    1 · Chunk

    Documents are split into overlapping passages of about 600 characters, keeping paragraph boundaries.

    2 · Retrieve

    BM25 ranking with light stemming, so Slovenian word forms (cena, cene, ceni) match, plus a small English-Slovenian glossary so an English question finds a Slovenian price list. Runs locally, nothing is sent anywhere.

    3 · Answer

    Only the top 6 passages go to the model, with the rule: answer from these or say you don't know, cite every claim as [n].

    4 · Measure

    A small test set measures retrieval quality, so changes to chunking or ranking can be compared with numbers.
