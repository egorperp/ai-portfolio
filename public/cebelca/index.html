Partners:

1 · MCP tools

The assistant sees 9 tools: search partners, list invoices, calculate VAT totals, create a draft, add a payment, issue the invoice, download the PDF. The same tools run in the Python server for Claude Desktop, ChatGPT or n8n.

2 · Preview, then confirm

Write tools return a preview with VAT per rate unless called with confirm=true. The assistant has to show it and wait for a yes. Issued invoices cannot be issued twice.

3 · Validation

Only Slovenian VAT rates (22, 9.5, 5, 0), no negative prices, discounts 0 to 100 %. IDs must be looked up, never guessed.

4 · Real API

In test or live mode the server calls cebelca.biz/API?_r=…&_m=… with the token kept in its environment, never in the prompt. Fiscal cash invoices are out of scope.
